# 📝 FitPulse 작업 로그

| 항목 | 내용 |
|------|------|
| 문서 유형 | 작업 로그 (Work Log) |
| 버전 | v1.0 |
| 작성 주기 | 매일 EOD (업무 종료 시) |
| 주간 요약 | 매주 금요일 |
| 연동 | GitHub Issues (WBS ID 라벨), PR 링크 |

---

## 1. 작성 규칙

| 항목 | 규칙 |
|------|------|
| 작성 시점 | 매일 업무 종료 시, 5분 이내 |
| 작업 식별 | WBS ID(예: 5.3) + GitHub Issue 번호 병기 |
| 블로커 | 발견 즉시 Slack `#fitpulse-dev` 공유 후 로그에 기록 |
| 진행률 | 완료 / 진행 중(%) / 미착수 3단계 |
| 주간 요약 | 금요일에 한 주치를 압축해 마일스톤 진척과 리스크 갱신 |

---

## 2. 일일 작업 로그 템플릿

```markdown

- [WBS x.x / #이슈번호] 작업 내용 — PR #번호

**🔄 진행 중**
- [WBS x.x / #이슈번호] 작업 내용 (진행률 %) — 예상 완료: MM-DD

**📌 내일 예정**
- [WBS x.x] 작업 내용

**⏱ 소요 시간**: 개발 Xh / 디버깅 Xh / 회의 Xh
```
