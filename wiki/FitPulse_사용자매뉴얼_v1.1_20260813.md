## 1. FitPulse 소개

FitPulse는 운동 기록과 건강 데이터를 한곳에서 관리하고, 내 기록을 바탕으로 운동 루틴을 추천받는 앱입니다.

**이런 분께 맞습니다**
- 헬스장에서 세트·중량을 빠르게 기록하고 싶은 분
- 인터넷이 잘 안 터지는 곳에서도 기록이 사라지지 않기를 바라는 분
- 걸음수·심박수·수면을 운동 기록과 함께 보고 싶은 분
- 내 수준과 부상 이력에 맞는 루틴을 추천받고 싶은 분

**주요 기능**

| 기능 | 설명 |
|------|------|
| 운동 기록 | 세션·종목·세트 기록, 휴식 타이머, RPE(체감 강도) |
| 오프라인 지원 | 인터넷이 없어도 기록되고, 연결되면 자동으로 저장됩니다 |
| 루틴 | 나만의 루틴 만들기, 요일 배정, 수정해도 이전 버전 보관 |
| 루틴 공유 | 내 루틴 공개, 다른 사람 루틴 둘러보기·좋아요·복사, 인기 랭킹 |
| 분석 | 볼륨 추이, 추정 1RM, 부위별 빈도, 운동 캘린더, 연속 기록 |
| 건강 데이터 | 건강 커넥트 연동으로 걸음수·심박·수면 자동 수집 |
| AI 루틴 추천 | 내 목표·이력·부상 정보를 반영한 루틴 제안 |

> ℹ️ FitPulse가 제공하는 모든 분석과 추천은 **참고용 피트니스 정보이며, 의학적 진단이 아닙니다.** 통증이나 이상이 있으면 전문가와 상담하세요.

## 2. 시작하기

### 2.1 설치

1. Google Play 스토어에서 **FitPulse**를 검색합니다.
2. [설치]를 누릅니다.
3. 설치가 끝나면 [열기]를 누릅니다.

`[스크린샷: 스토어 설치 화면]`

**필요 환경**: Android 9 이상 (건강 커넥트 자동 동기화는 Android 14 이상에서 가장 원활합니다)

### 2.2 회원가입

**방법 A — 이메일로 가입**

1. 첫 화면에서 [이메일로 시작하기]를 누릅니다.
2. 이메일, 비밀번호, 이름을 입력합니다.
   - 비밀번호는 8자 이상이며, 영문·숫자·특수문자 중 2종류 이상을 포함해야 합니다.
3. 약관 화면에서 동의 항목을 확인합니다.
4. [가입하기]를 누릅니다.

`[스크린샷: 이메일 가입 화면]`

**방법 B — Google 계정으로 시작**

1. 첫 화면에서 [Google로 계속하기]를 누릅니다.
2. 사용할 Google 계정을 선택합니다.
3. 약관 동의 후 [시작하기]를 누릅니다.

`[스크린샷: Google 로그인 화면]`

### 2.3 동의 항목 이해하기

| 항목 | 필수 여부 | 동의하지 않으면 |
|------|-----------|-----------------|
| 이용약관 | 필수 | 가입할 수 없습니다 |
| 개인정보처리방침 | 필수 | 가입할 수 없습니다 |
| 건강 데이터 수집 | 선택 | 건강 커넥트 연동 없이 직접 입력만 가능합니다 |
| AI 분석 활용 | 선택 | AI 루틴 추천을 사용할 수 없습니다 |
| 마케팅 수신 | 선택 | 소식·혜택 안내를 받지 않습니다 |

선택 항목은 **가입 후 언제든 [설정 > 개인정보 및 동의]에서 변경**할 수 있습니다.

### 2.4 초기 설정 (프로필과 목표)

1. 가입 후 안내에 따라 성별, 출생연도, 키를 입력합니다.
2. 운동 목표를 선택합니다 — 근육 증가 / 체지방 감소 / 근력 향상 / 유지
3. 주간 운동 일수와 경험 수준(초급·중급·고급)을 선택합니다.
4. 보유한 장비를 선택합니다 (바벨, 덤벨, 머신 등).
5. **부상 이력이 있다면 반드시 입력하세요.** AI 루틴 추천에서 해당 부위에 무리가 되는 운동을 제외하는 데 사용됩니다.

`[스크린샷: 목표 설정 화면]`

## 3. 기능별 사용 방법

### 3.1 운동 기록하기

**세션 시작**

1. 홈 화면 하단의 [＋ 운동 시작] 버튼을 누릅니다.
2. 빈 세션으로 시작하거나, 저장된 루틴을 선택합니다.
3. 세션 화면이 열리고 시간이 자동으로 측정되기 시작합니다.

`[스크린샷: 세션 시작 화면]`

**종목과 세트 기록**

1. [＋ 운동 추가]를 눌러 운동을 검색하고 선택합니다.
2. 세트 줄에 중량(kg)과 횟수를 입력합니다.
3. 세트를 마쳤으면 오른쪽 체크 버튼을 누릅니다 → 휴식 타이머가 자동 시작됩니다.
4. [＋ 세트 추가]로 다음 세트를 이어서 기록합니다.

`[GIF: 세트 입력 → 체크 → 타이머 시작]`

> 💡 **RPE**란? 그 세트가 얼마나 힘들었는지를 1~10으로 남기는 값입니다. 10은 한 번도 더 못 할 정도, 8은 2회 정도 여유가 있는 상태입니다. 선택 입력이며, 기록해두면 강도 변화를 파악하기 좋습니다.

**세션 완료**

1. 모든 운동을 마치면 [운동 완료]를 누릅니다.
2. 기분(아주 좋음~나쁨)과 메모를 남길 수 있습니다.
3. 완료하면 총 운동 시간, 총 볼륨(중량×횟수 합계), 예상 소모 칼로리가 요약됩니다.

`[스크린샷: 완료 요약 화면]`

**세트 수정·삭제**: 세트 줄을 길게 누르면 수정·삭제 메뉴가 나타납니다. 수정하면 총 볼륨도 자동으로 다시 계산됩니다.

### 3.2 오프라인에서 기록하기

지하 헬스장처럼 인터넷이 불안정한 곳에서도 그대로 사용하시면 됩니다.

1. 인터넷이 끊겨도 기록은 **기기에 먼저 저장**됩니다.
2. 화면 상단에 `오프라인 · 저장 대기 N건` 배지가 표시됩니다.
3. 인터넷이 연결되면 **자동으로 전송**되고 배지가 사라집니다.

`[스크린샷: 오프라인 배지]`

**앱이 꺼져도 안전합니다.** 앱을 다시 실행하면 진행 중이던 운동이 그대로 복구됩니다.

**"저장 대기가 많습니다" 경고가 뜬다면**: 오랫동안 인터넷에 연결되지 않아 대기 중인 기록이 500건을 넘은 상태입니다. Wi-Fi나 데이터 연결을 확인해 주세요.

**"동기화 충돌" 안내가 뜬다면**: 다른 기기에서 같은 기록을 변경했거나, 이미 삭제된 항목을 수정하려 한 경우입니다. 안내 화면에서 [내 기록 유지] 또는 [이번 변경 취소] 중 하나를 선택하시면 됩니다.

### 3.3 루틴 만들기

1. 하단 [루틴] 탭 → [＋ 새 루틴]을 누릅니다.
2. 루틴 이름, 목표, 난이도를 입력합니다.
3. [＋ 일자 추가]로 Day를 만들고, 각 Day에 운동을 추가합니다.
   - 목표 세트 수, 목표 횟수 범위(예: 8-12), 휴식 시간을 지정합니다.
   - 휴식일은 [휴식일로 지정]을 켜두면 됩니다.
4. [저장]을 누릅니다.
5. [요일 배정]에서 각 Day를 요일에 배치하면 홈 화면에 "오늘의 루틴"이 표시됩니다.

`[스크린샷: 루틴 편집 화면]`

> 💡 루틴을 수정해도 **이전 버전은 그대로 보관**됩니다. [루틴 상세 > 버전 기록]에서 예전 구성을 확인할 수 있습니다.

### 3.4 분석 보기

하단 [분석] 탭에서 확인할 수 있습니다.

| 화면 | 보는 방법 |
|------|-----------|
| 볼륨 추이 | 주/월 단위로 총 운동량 변화를 확인합니다 |
| 추정 1RM | 운동을 선택하면 최대 중량 추정치의 변화를 보여줍니다 |
| 부위별 빈도 | 어느 부위를 많이/적게 했는지 균형을 확인합니다 |
| 운동 캘린더 | 잔디 형태로 한눈에 운동일을 확인합니다 |
| 연속 기록 | 현재 연속 운동일과 최장 기록을 보여줍니다 |

`[스크린샷: 분석 탭]`

> ℹ️ **추정 1RM은 계산된 값입니다.** 실제 1회 최대 중량과 다를 수 있으니 참고용으로만 사용하고, 실제 고중량 시도는 안전 장비와 보조자를 갖춘 상태에서 하세요.


### 3.4-1 루틴 공유하고 둘러보기

**다른 사람의 루틴 둘러보기**

1. [루틴] 탭 → [둘러보기]를 누릅니다.
2. 인기순 / 최신순으로 정렬하거나, 목표·난이도·주간 일수로 걸러서 볼 수 있습니다.
3. 마음에 드는 루틴을 누르면 구성 전체를 볼 수 있습니다.
4. [내 루틴으로 복사]를 누르면 내 루틴 목록에 복사됩니다. 복사한 뒤에는 자유롭게 수정해도 원본에 영향을 주지 않습니다.
5. 하트 버튼으로 [좋아요]를 누를 수 있습니다. 좋아요와 복사 수가 많은 루틴은 인기 랭킹 상위에 올라갑니다.

`[스크린샷: 루틴 둘러보기 화면]`

**내 루틴 공개하기**

1. 공개하려는 루틴 상세에서 [공개하기]를 누릅니다.
2. 다른 사람에게 보일 이름과 설명을 입력합니다.
3. [공개 요청]을 누르면 **검토 후 공개**됩니다. 검토는 보통 1~2일 걸립니다.
4. 공개된 후에는 [비공개로 전환]으로 언제든 내릴 수 있습니다.

> ℹ️ 공개 루틴은 **검토를 거쳐 게시**됩니다. 부상 위험이 크거나 부적절한 내용은 반려될 수 있으며, 반려 시 사유를 알려드립니다.

**신고하기**

부적절하거나 위험해 보이는 루틴을 발견하면 상세 화면의 [⋯ > 신고]를 눌러주세요. 사유(부적절함 / 위험함 / 스팸 / 저작권)를 선택하고 설명을 남기면 검토 후 조치합니다. 신고가 일정 수 이상 쌓이면 검토가 끝날 때까지 해당 루틴은 자동으로 숨겨집니다.

> ⚠️ **공개 루틴은 다른 사용자가 만든 것입니다.** 검토를 거치지만 모든 사람에게 안전한 강도라고 보장할 수는 없습니다. 본인의 경험 수준과 몸 상태에 맞게 조정해서 사용하시고, 통증이 있으면 즉시 중단하세요.

### 3.4-2 이용 제한 안내

커뮤니티 규칙을 반복해서 어기면 다음과 같은 조치가 있을 수 있습니다.

| 조치 | 내용 |
|------|------|
| 콘텐츠 숨김 | 해당 루틴만 공개 목록에서 제외 |
| 공개 권한 정지 | 일정 기간 루틴을 공개할 수 없음 (기록·분석은 정상 이용) |
| 이용 정지 | 일정 기간 앱 이용 제한 |
| 영구 정지 | 재가입 불가 |

조치를 받으면 앱 알림과 [설정 > 이용 제한 안내]에서 사유와 기간을 확인할 수 있습니다. **부당하다고 생각되면 1회 이의제기**를 할 수 있으며, 재검토 후 결과를 알려드립니다.

### 3.5 건강 데이터 연동 (건강 커넥트)

**연동하기**

1. [건강] 탭 → [건강 커넥트 연동하기]를 누릅니다.
2. 사용 목적 안내를 확인합니다.
   - 걸음수로 활동량 추적
   - 심박수로 운동 강도 분석
   - 수면 데이터로 회복 상태 파악
3. [연동하기]를 누르고, 건강 커넥트 화면에서 허용할 항목을 선택합니다.

`[스크린샷: 권한 요청 화면]`

**지금은 연동하고 싶지 않다면** [나중에 하기]를 누르세요. 체중 등은 직접 입력해서 계속 사용할 수 있고, 나중에 [설정 > 건강 데이터]에서 언제든 연동할 수 있습니다.

**동기화 시점**: 앱을 열 때, 새 데이터가 생겼을 때(Android 14 이상), [새로고침]을 누를 때 자동으로 갱신됩니다.

**체성분 직접 입력**

1. [건강] 탭 → [체성분 기록]을 누릅니다.
2. 체중, 체지방률, 근육량을 입력합니다 (아는 값만 입력해도 됩니다).
3. [저장]을 누르면 추이 그래프에 반영됩니다.

**연동 해제**: [설정 > 건강 데이터 > 연동 해제]에서 해제할 수 있습니다. 이때 이미 가져온 데이터를 삭제할지 선택할 수 있습니다.

### 3.6 AI 루틴 추천 받기

1. [루틴] 탭 → [AI 추천 받기]를 누릅니다.
2. 원하는 조건(주 몇 회, 1회 몇 분, 집중 부위)을 선택합니다.
3. [추천 받기]를 누르면 잠시 생성 중 화면이 표시됩니다 (보통 30초 이내).
4. 제안된 루틴을 확인합니다.
   - 운동을 바꾸거나, 세트 수를 조정하거나, 필요 없는 운동을 뺄 수 있습니다.
5. 마음에 들면 [내 루틴으로 저장], 아니면 [다시 추천]을 누릅니다.

`[스크린샷: AI 추천 결과 화면]`

**알아두실 점**

- AI 추천은 **하루 10회**까지 사용할 수 있습니다.
- 프로필에 입력한 **부상 이력이 반영**되어 해당 부위에 부담이 큰 운동은 제외됩니다.
- 추천이 일시적으로 어려울 때는 경험 수준에 맞는 **기본 루틴**을 대신 제안합니다.
- 이름·이메일 같은 개인 정보는 AI에 전달되지 않습니다.

> ℹ️ AI 추천은 참고용 피트니스 인사이트이며, 의학적 진단이나 처방이 아닙니다.

### 3.7 계정과 개인정보 관리

| 하고 싶은 일 | 경로 |
|--------------|------|
| 내 기기 확인·로그아웃 | 설정 > 내 기기 관리 |
| 동의 항목 변경 | 설정 > 개인정보 및 동의 |
| 내 데이터 내려받기 | 설정 > 데이터 내보내기 |
| 계정 삭제 | 설정 > 계정 삭제 |

**기기는 최대 5대까지** 동시에 로그인할 수 있습니다. 6번째 기기에서 로그인하면 가장 오래 전에 로그인한 기기가 자동으로 로그아웃됩니다.

**계정 삭제 시**: 요청 후 **30일간 유예 기간**이 있습니다. 이 기간에 다시 로그인하면 계정이 복구되고, 30일이 지나면 모든 데이터가 완전히 삭제되어 되돌릴 수 없습니다.

## 4. 자주 묻는 질문 (FAQ)

**Q. 인터넷이 없어도 운동을 기록할 수 있나요?**
A. 네. 기록은 기기에 먼저 저장되고, 연결되면 자동으로 전송됩니다. 앱을 강제로 종료해도 기록은 남아 있습니다.

**Q. 상단에 "저장 대기 12건"이라고 뜨는데 문제가 있나요?**
A. 아직 서버로 전송되지 않은 기록이 12건 있다는 뜻입니다. 인터넷에 연결되면 자동으로 사라집니다. 기록이 사라진 것이 아니니 안심하셔도 됩니다.

**Q. 걸음수가 앱에 안 보여요.**
A. ① [설정 > 건강 데이터]에서 연동 상태를 확인하고, ② 건강 커넥트 앱에서 FitPulse에 걸음수 권한이 허용되어 있는지 확인한 뒤, ③ [건강] 탭에서 [새로고침]을 눌러보세요.

**Q. 오래 사용하지 않다가 다시 열었더니 건강 데이터를 다시 불러옵니다.**
A. 건강 커넥트의 변경 추적 정보는 약 30일이 지나면 만료됩니다. 이 경우 최근 90일 데이터를 다시 확인해 빠진 부분을 채우는 과정으로, 중복 저장되지는 않습니다.

**Q. AI 추천에 부상 부위 운동이 들어 있어요.**
A. [설정 > 운동 목표]의 부상 메모가 비어 있거나 부위가 명확하지 않을 수 있습니다. "왼쪽 어깨 회전근개"처럼 부위를 구체적으로 적어주시고, 그래도 반복되면 앱 내 문의로 알려주세요.

**Q. 다른 기기에서 로그인했더니 원래 기기가 로그아웃됐어요.**
A. 보안을 위해 동시 로그인은 5대까지만 지원합니다. 6번째 로그인 시 가장 오래된 기기가 자동 로그아웃됩니다.

**Q. 추정 1RM이 실제와 달라요.**
A. 계산 공식에 기반한 추정치이며, 반복 횟수가 많을수록 오차가 커집니다. 12회를 초과한 세트는 계산에서 제외됩니다. 절대값보다는 **변화 추이**를 보는 용도로 활용하세요.

**Q. 공개 요청한 루틴이 아직 안 보여요.**
A. 공개 루틴은 검토를 거쳐 게시되며 보통 1~2일 걸립니다. [루틴 상세]에서 "검토 중" 상태를 확인할 수 있고, 반려된 경우 사유가 표시됩니다.

**Q. 좋아요를 눌렀는데 숫자가 안 올라갑니다.**
A. 이미 좋아요를 누른 상태일 수 있습니다. 하트가 채워져 있으면 이미 반영된 상태입니다. 또한 **자기 루틴에는 좋아요를 누를 수 없습니다.**

**Q. 잘 보이던 루틴이 갑자기 안 보여요.**
A. 신고가 접수되어 검토 중이거나, 작성자가 비공개로 전환했을 수 있습니다. 이미 내 루틴으로 복사해둔 경우에는 그대로 사용할 수 있습니다.

**Q. 앱이 "점검 중"이라고 나오는데 운동 기록은 어떻게 하나요?**
A. 점검 중에도 **운동 기록은 평소처럼 하시면 됩니다.** 기기에 저장되었다가 점검이 끝나면 자동으로 전송됩니다.

**Q. 탈퇴하면 바로 삭제되나요?**
A. 30일 유예 후 완전 삭제됩니다. 유예 기간 중 로그인하면 복구됩니다.

**Q. 내 데이터를 백업할 수 있나요?**
A. [설정 > 데이터 내보내기]에서 JSON 파일로 내려받을 수 있습니다.
