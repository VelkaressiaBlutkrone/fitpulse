# 🔐 FitPulse 관리자 매뉴얼

| 항목 | 내용 |
|------|------|
| 문서 유형 | 사용자 매뉴얼 (관리자용) |
| 버전 | v1.0 |
| 작성일 | 2026-08-13 |
| 대상 | 관리자 콘솔 이용자 (SUPER_ADMIN / ADMIN / OPERATOR / SUPPORT / VIEWER) |
| 접근 | 공개 역사 설계 예시; 실제 운영 매뉴얼 아님 |

> ⚠️ **공개 역사 설계 초안** — 실제 관리자 계정, 내부 주소, 복구 코드, 승인자 연락처와 제한 운영 절차는 포함하지 않습니다. 실제 운영 매뉴얼이 필요하면 접근 통제된 별도 저장소에서 새로 작성해야 합니다.

---

## 1. 시작하기 전에 — 반드시 알아둘 4가지

| # | 원칙 | 의미 |
|---|------|------|
| 1 | **모든 행동이 기록됩니다** | 회원 정보를 "보기만" 해도 기록됩니다. 기록은 누구도 지울 수 없고 3년간 보관됩니다. |
| 2 | **회원 데이터는 고칠 수 없습니다** | 운동 기록·건강 데이터를 관리자가 수정하는 기능은 아예 없습니다. 정정이 필요하면 회원 본인이 앱에서 하도록 안내하세요. |
| 3 | **되돌리기 어려운 일은 혼자 못 합니다** | 영구정지·즉시삭제·설정변경은 다른 관리자 승인이 필요합니다. |
| 4 | **필요한 것만 보세요** | 개인정보는 기본적으로 가려져 있습니다. 업무상 꼭 필요할 때만, 사유를 적고 해제하세요. |

## 2. 로그인

### 2.1 최초 접속 (초대 수락)

1. 관리자 초대 이메일의 링크를 엽니다. **링크는 72시간 후 만료**됩니다.
2. 비밀번호를 설정합니다 — **12자 이상**, 영문 대소문자·숫자·특수문자 조합 권장.
3. 화면의 QR 코드를 인증 앱(Google Authenticator, Authy 등)으로 스캔합니다.
4. 인증 앱에 표시된 6자리 숫자를 입력해 등록을 완료합니다.
5. **백업 코드 10개가 표시됩니다. 안전한 곳에 별도 보관하세요.** 휴대폰을 분실했을 때 이 코드로만 로그인할 수 있습니다.

`[스크린샷: TOTP 등록 화면]`

### 2.2 일상 로그인

1. 이메일·비밀번호 입력
2. 인증 앱의 6자리 코드 입력 (30초마다 갱신)
3. 로그인 완료

| 상황 | 조치 |
|------|------|
| 비밀번호 5회 틀림 | **30분 잠깁니다.** 급하면 SUPER_ADMIN에게 해제 요청 |
| 인증 앱을 못 쓰는 상황 | 백업 코드 사용 (1개당 1회) |
| 백업 코드도 없음 | SUPER_ADMIN에게 TOTP 초기화 요청 (본인 확인 절차 필요) |
| "허용되지 않은 IP" | 사내망/VPN 연결 확인 |

### 2.3 세션 규칙

| 항목 | 값 |
|------|-----|
| 자동 로그아웃 | **30분 무조작 시** |
| 최대 접속 시간 | 로그인 후 **8시간** (활동 중이어도 만료) |
| 동시 로그인 | **2대까지** (3대째 로그인 시 가장 오래된 것이 끊김) |

> 자리를 비울 때는 화면을 잠그거나 로그아웃하세요. 30분은 생각보다 깁니다.

## 3. 역할별로 할 수 있는 일

| 역할 | 주 담당 | 할 수 있는 일 | 할 수 없는 일 |
|------|---------|---------------|---------------|
| **SUPER_ADMIN** | 총괄 | 전부 | - |
| **ADMIN** | 운영 총괄 | 회원 정지, 제재 집행, 프롬프트 활성화, 감사 로그 조회 | 관리자 계정·역할 관리 / 영구정지·삭제·설정변경은 승인 필요 |
| **OPERATOR** | 콘텐츠 운영 | 운동·루틴·공지 관리, 신고 처리, 매핑 검수 | 회원 개인정보 해제, 계정 제재, 감사 로그 |
| **SUPPORT** | 고객 지원 | 회원 조회, 개인정보 해제(사유 필수), 강제 로그아웃 | 계정 제재, 콘텐츠 수정 |
| **VIEWER** | 참관 | 조회 전용 | 모든 쓰기 작업 |

권한이 없는 메뉴는 화면에 보이지 않거나, 실행 시 "권한이 없습니다"와 함께 **필요한 권한 이름**이 표시됩니다. 업무상 필요하면 SUPER_ADMIN에게 역할 조정을 요청하세요.

## 4. 회원 관리

### 4.1 회원 찾기

1. [회원] 메뉴 → 검색창에 이메일·닉네임·회원 ID 입력
2. 가입일·상태·가입경로로 필터링

목록에는 개인정보가 가려져 표시됩니다 (`ho***@gm***.com`, `홍**`).

### 4.2 개인정보 확인하기 (마스킹 해제)

1. 회원 상세에서 [개인정보 보기]를 누릅니다.
2. **사유를 입력합니다** (10자 이상). 예: `고객센터 문의 #4821 본인 확인`
3. 확인을 누르면 원본이 표시됩니다.

> 📌 **이 행위는 기록됩니다.** 언제, 누가, 어떤 회원의 정보를, 어떤 사유로 봤는지 남습니다.
> 한 시간에 30회를 넘으면 차단되고 보안 담당에게 알림이 갑니다. 목록을 훑어보는 용도로 사용하지 마세요.

### 4.3 강제 로그아웃

회원이 "기기를 잃어버렸다", "누가 내 계정을 쓰는 것 같다"고 문의할 때 사용합니다.

1. 회원 상세 → [기기 목록]
2. 특정 기기만 끊거나 [전체 로그아웃] 선택
3. 회원에게 재로그인을 안내

### 4.4 이용 정지

1. 회원 상세 → [상태 변경] → `이용정지` 선택
2. **사유와 기간을 입력합니다** (사유는 회원에게 그대로 전달됩니다)
3. 확인 → 즉시 적용되며 회원의 모든 세션이 끊깁니다

| 조치 | 권한 | 승인 |
|------|------|------|
| 이용정지(기간) | ADMIN 이상 | 불필요 |
| **영구정지** | ADMIN 이상 | **다른 관리자 승인 필요** |
| **즉시 삭제** | ADMIN 이상 | **다른 관리자 승인 필요** |

> 정지된 회원도 **자기 데이터는 그대로 보존**됩니다. 기간이 끝나면 자동으로 풀립니다.

### 4.5 데이터 내보내기 대행

회원이 직접 [설정 > 데이터 내보내기]를 쓸 수 있으므로, 대행은 **본인 확인이 끝난 예외적인 경우**에만 사용합니다. 다른 관리자 승인이 필요하며 전 과정이 기록됩니다.

## 5. 콘텐츠 관리

### 5.1 운동 라이브러리

| 작업 | 방법 |
|------|------|
| 운동 추가 | [콘텐츠 > 운동] → [＋ 등록] → 이름(한/영)·부위·장비·난이도 입력 |
| 운동 수정 | 목록에서 선택 → 수정 |
| 운동 내리기 | [보관 처리] — **삭제 버튼은 없습니다** |
| 대량 등록 | [CSV 업로드] → 검증 결과 확인 → [확정 반영] |

> 🔒 운동은 **삭제되지 않고 보관 처리만** 됩니다. 회원들의 과거 운동 기록이 그 운동을 참조하고 있어서, 삭제하면 기록이 깨집니다. 보관 처리하면 새 검색에서만 빠지고 기존 기록은 그대로 보입니다.

**CSV 업로드 절차**: 파일을 올리면 먼저 **검사만** 합니다. 몇 행에 어떤 문제가 있는지 알려주므로, 수정 후 다시 올리거나 유효한 행만 확정하세요.

### 5.2 공개 루틴 심사

1. [콘텐츠 > 공개 심사]에서 대기 목록 확인
2. 루틴 구성을 열어 확인 — 특히 다음을 봅니다
   - 초보자 대상인데 과도한 중량·세트인가
   - 부상 위험이 큰 동작을 무리하게 권하는가
   - 광고·스팸·타 서비스 유도 목적인가
3. [승인] 또는 [반려] — **반려 시 사유를 적어주세요.** 작성자에게 그대로 전달됩니다.

이미 공개된 루틴도 문제가 발견되면 [숨김 처리]할 수 있습니다.

### 5.3 공지사항

1. [콘텐츠 > 공지] → [＋ 작성]
2. 유형 선택: 일반 / 점검 / 이벤트 / 긴급
3. 게시 예약 시각과 종료 시각을 지정할 수 있습니다
4. 대상: 전체 / 특정 플랫폼 / 특정 버전 이상

### 5.4 점검 모드

정기 점검이나 장애 대응 시 사용합니다.

1. [설정 > 점검 모드] → 켜기
2. 안내 문구와 예상 종료 시각 입력
3. 사유 입력 후 확인

**점검 모드에서 일어나는 일**

| 대상 | 동작 |
|------|------|
| 사용자 쓰기 (기록 저장, 동기화) | 차단 |
| 사용자 읽기 (조회) | 정상 |
| **앱의 운동 기록** | **기기에 저장됨 → 점검 종료 후 자동 전송** |
| 관리자 콘솔 | 정상 |

> 💡 점검 중에도 회원들은 운동을 기록할 수 있습니다. 오프라인 큐가 처리하므로 데이터가 유실되지 않습니다. 공지에도 이 점을 안내하면 문의가 줄어듭니다.

## 6. 신고 처리

### 6.1 처리 흐름

```
신고 접수 → [신고 큐] 확인 → 대상 확인 → 수용 / 기각 → (수용 시) 제재 집행
                 ↑
        신고 5건 누적 시 자동 숨김 (임시 조치)
```

**자동 숨김은 최종 결정이 아닙니다.** 신고가 쌓여 일단 가려둔 상태이므로, 반드시 검토해서 확정하거나 해제해야 합니다.

### 6.2 처리 방법

1. [신고] 메뉴에서 오래된 것부터 확인 (기본 정렬)
2. 같은 대상에 대한 신고는 묶여서 보입니다 — 누적 건수를 함께 참고하세요
3. 대상(루틴·운동·회원)을 직접 열어 확인
4. [수용] 또는 [기각] + 처리 메모 작성
5. 수용한 경우 제재 수위를 결정

### 6.3 제재 수위 기준

| 상황 | 권장 조치 |
|------|-----------|
| 내용은 문제없으나 부정확 | 콘텐츠 숨김 + 작성자 안내 |
| 위험한 강도를 반복 게시 | 공개 권한 정지 (7~30일) |
| 광고·스팸 반복 | 공개 권한 정지 + 경고 |
| 타인 비방·괴롭힘 | 이용 정지 (7~30일) |
| 심각한 위반 또는 반복 누적 | 영구 정지 (**승인 필요**) |

반복 위반 회원은 시스템이 가중 조치를 제안합니다. 제안은 참고용이며 최종 판단은 담당자가 합니다.

### 6.4 이의제기

회원은 제재에 대해 **1회 이의제기**할 수 있습니다. [이의제기] 메뉴에서 확인하고, 재검토 후 [제재 유지] 또는 [제재 해제]를 선택합니다. 해제하면 회원은 즉시 정상 상태로 돌아갑니다.

## 7. AI 운영

### 7.1 프롬프트 관리

AI 추천 품질이 떨어졌다는 보고가 들어오면 여기서 대응합니다.

**새 버전 적용**
1. [AI > 프롬프트] → [＋ 새 버전]
2. 내용 작성 후 저장 (아직 적용 안 됨)
3. **[시험 실행]을 먼저 하세요** — 샘플 회원 데이터로 결과·검증 통과 여부·비용을 확인합니다
4. 문제없으면 [활성화]

**롤백**
1. 이전 버전 선택 → [이 버전으로 되돌리기]
2. **즉시 적용됩니다. 서버 재배포가 필요 없습니다.**

> ⚠️ 프롬프트 활성화는 **모든 회원의 다음 AI 요청부터 바로 영향**을 줍니다. 시험 실행을 건너뛰지 마세요. 문제가 생기면 롤백이 가장 빠른 해결책입니다.

### 7.2 운동 매핑 검수

AI가 만든 운동 이름을 우리 DB의 운동과 자동으로 연결하는데, 확신이 낮은 건은 사람이 확인해야 합니다.

1. [AI > 매핑 검수] → 미검증 목록 확인
2. 각 항목의 `AI가 말한 이름` ↔ `연결된 운동`이 맞는지 확인
3. 맞으면 [승인] / 틀리면 [다른 운동으로 연결] / 무의미하면 [삭제]

승인된 매핑은 이후 자동으로 재사용되어 AI 호출 비용과 실패율을 낮춥니다. **주 1회 정도 검수하면 충분합니다.**

### 7.3 비용 관리

[AI > 비용]에서 일별·월별 추이와 사용량 상위 회원을 볼 수 있습니다.

| 상황 | 조치 |
|------|------|
| 비용이 서서히 증가 | 정상 (사용자 증가) — 추이만 관찰 |
| 특정 회원이 비정상적으로 많이 사용 | 해당 회원 한도 조정 검토 |
| 하루 만에 급증 | 프롬프트가 길어졌는지 확인, 필요 시 한도 하향 |
| **통제 불가 수준** | **[AI 긴급 차단] 사용** |

### 7.4 AI 긴급 차단 (킬 스위치)

AI 제공사 장애나 비용 폭증 시 사용합니다.

1. [AI > 긴급 차단] → 켜기 + 사유 입력
2. 이후 AI 요청은 외부 호출 없이 **기본 템플릿 루틴**으로 응답합니다

> 회원 입장에서는 "AI 추천을 생성할 수 없어 기본 루틴을 제안합니다"라는 기존 안내가 보일 뿐, 오류 화면이 뜨지 않습니다. 기능이 완전히 멈추지는 않습니다.

## 8. 통계와 감사 로그

### 8.1 운영 통계

[통계] 메뉴에서 DAU/MAU, 신규 가입, 세션 완료 수, 리텐션(D1/D7/D30)을 확인합니다. CSV로 내려받을 수 있으며, **개인식별정보는 포함되지 않습니다.**

### 8.2 감사 로그 (AUDIT_READ 권한 필요)

1. [감사 로그] 메뉴
2. **기간을 반드시 지정합니다** (최대 90일, 그 이상은 CSV 내보내기 사용)
3. 관리자·행위 유형·대상으로 필터링

**이럴 때 확인하세요**
- 회원이 "내 계정이 갑자기 정지됐다"고 문의 → 누가 왜 정지했는지 확인
- 데이터가 이상하게 바뀜 → 관리자 조작 여부 확인
- 월 1회 정기 점검 → 개인정보 열람 이력에 이상 패턴이 없는지 확인

## 9. 2인 승인이 필요한 작업

### 9.1 대상

영구 정지 / 회원 즉시 삭제 / 데이터 내보내기 대행 / 민감 설정 변경 / AI 긴급 차단

### 9.2 절차

**요청하는 쪽**
1. 평소처럼 작업을 실행합니다
2. "다른 관리자의 승인이 필요합니다"라는 안내와 함께 요청이 접수됩니다
3. 다른 관리자에게 승인을 요청하세요 (**요청은 24시간 후 만료**됩니다)

**승인하는 쪽**
1. [승인 대기] 메뉴에서 요청 내용과 사유를 확인
2. 타당하면 [승인] → **즉시 실행**됩니다 / 아니면 [반려]

> 🔒 **본인이 요청한 것을 본인이 승인할 수는 없습니다.** 요청자와 승인자 모두 기록에 남습니다. 이 절차는 서로를 의심해서가 아니라, 되돌리기 어려운 실수를 한 사람의 판단에만 맡기지 않기 위한 것입니다.

## 10. 자주 겪는 상황

**Q. 회원이 "기록이 사라졌다"고 합니다.**
A. 오프라인 대기 중일 가능성이 큽니다. 회원 활동 이력에서 최근 동기화 시각을 확인하고, 앱 상단의 "저장 대기 N건" 배지 여부를 물어보세요. 인터넷 연결 후 자동 전송된다고 안내하면 대부분 해결됩니다.

**Q. 회원이 로그인이 안 된다고 합니다.**
A. ① 이용 정지 상태인지 확인 ② 기기 5대 초과로 자동 로그아웃됐는지 확인 ③ 필요하면 전체 강제 로그아웃 후 재로그인 안내.

**Q. 급한데 승인해줄 관리자가 없습니다.**
A. 영구정지 대신 **기간제 이용정지**를 먼저 적용하세요. 즉시 실행되며 회원 활동을 막을 수 있습니다. 승인은 나중에 받아 영구 전환하면 됩니다.

**Q. 권한이 없어서 못 하는 일이 계속 생깁니다.**
A. SUPER_ADMIN에게 역할 조정을 요청하세요. 다만 **필요 이상의 권한을 받지 않는 것이 서로에게 안전합니다.**

**Q. 실수로 잘못 정지시켰습니다.**
A. 즉시 [상태 변경]으로 해제하세요. 정지와 해제 모두 기록에 남지만, 감추려 하지 말고 사유에 사실대로 적으면 됩니다. 감사 로그의 목적은 처벌이 아니라 추적입니다.

**Q. 화면에 메뉴가 안 보입니다.**
A. 역할에 해당 권한이 없는 경우입니다. 3장의 권한 표를 확인하세요.

## 11. 하지 말아야 할 것

| 금지 | 이유 |
|------|------|
| 관리자 계정 공유 | 감사 추적이 무의미해지고, 사고 시 책임 소재 불명 |
| 업무 목적 없는 회원 정보 열람 | 개인정보 침해. 열람 자체가 기록되며 감사 대상 |
| 브라우저에 관리자 비밀번호 저장 | 단말 탈취 시 즉시 침해 |
| 사내망 밖(카페 Wi-Fi 등)에서 접속 시도 | IP 차단되며, 우회 시도는 보안 사고로 처리 |
| 백업 코드를 채팅·메모 앱에 보관 | 2FA가 무력화됨 |
| 사유란에 "확인", "요청" 등 형식적 입력 | 나중에 아무도 맥락을 알 수 없음. 문의 번호·근거를 남기세요 |
| DB 직접 조작 | 감사 기록이 남지 않음. **어떤 경우에도 금지** |
