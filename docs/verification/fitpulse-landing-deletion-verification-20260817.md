## 안내 문구와 코드 상수 일치

`landing/app/privacy/page.tsx`가 명시한 보존 기간이 `landing/db/landing-storage.ts`의 상수와 일치하는지 테스트로 검증한다.

| 안내 문구 | 코드 상수 | 상태 |
|---|---|---|
| 확인되지 않은 이메일 14일 | `PENDING_RETENTION_DAYS = 14` | 일치 |
| 그 밖 최대 365일 | `DATA_RETENTION_DAYS = 365` | 일치 |
| 요청 제한 기록 1시간 | 정리 질의의 3600초 기준 | 일치 |
| 확인 링크 14일 만료 | `isoAfter(now, PENDING_RETENTION_DAYS)` | 일치 |

상수를 바꾸면 테스트가 실패하므로 안내와 코드가 조용히 어긋날 수 없다.

## 안내에 반영한 불리한 사실

검산 과정에서 확인한 한계를 안내 문구에 그대로 적었다. 감추지 않는다.

| 사실 | 근거 |
|---|---|
| 저장 국가를 특정할 수 없음 | 배포 환경이 데이터 레지던시를 지원하지 않음 (WF-07) |
| 삭제 후 플랫폼 내부 최대 30일 잔존 | WF-07 확인 |
| 예약 작업 미지원으로 정리가 지연될 수 있음 | WF-07·WF-09 |
| 수탁 구조가 2단(플랫폼 → 재위탁) | WF-07 |
| 재위탁 사업자가 페이지에 분류기 실행 | WF-07 |
| 실제 발송 공급자 미연결 | WF-03 |
