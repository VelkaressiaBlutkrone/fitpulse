# ADR-20260814-001: 개인사업자 1인 자체 검토 거버넌스

Status: ACCEPTED — OWNER-DIRECTED; DOES NOT GRANT EXECUTION AUTHORITY

Decision date: 2026-08-14

Applies to: FitPulse V0·V1·V2 사전 제품 검증

## 결정

FitPulse의 계약·예산 책임 주체를 개인 프로젝트가 아닌 **개인사업자**로 기록하고, V0·V1·V2의 거버넌스를 `SOLE_PROPRIETOR_SELF_REVIEW`로 운영한다.

개인사업자 본인 한 명을 `R-OWNER`로 두고 다음 기능을 모두 겸임한다.

- `R-SPONSOR`: 시간·비용 상한과 `GO/LOOP/STOP` 결정
- `R-PRODUCT`: 문제·웨지·범위와 문서 버전 관리
- `R-EVIDENCE`: 모집·동의·원자료 계보·집계 관리
- `R-USER`: 사용자 관점 체크리스트 수행
- `R-PRIVACY`: 수집 최소화·접근·보존·삭제·사고 중단 판단
- `R-VERIFY`: 동결된 규칙과 입력으로 재실행하는 자체 검산
- `R-FINANCE`: 오퍼·결제·환불·비용 산식 관리

이 기능명은 책임 누락을 막기 위한 모자(hat)이며 서로 다른 사람이나 외부 인력을 뜻하지 않는다. 참가자와 외부 전문가는 조사 대상 또는 자문 제공자일 수 있지만, 이 결정만으로 상시 역할 담당자나 독립 승인자가 되지 않는다.

## 증거 등급과 주장 제한

한 사람이 가설 작성, 조사, 분류, 개인정보 검토와 게이트 결정을 모두 수행하므로 결과의 보증 수준은 다음으로 고정한다.

~~~yaml
governance_model: SOLE_PROPRIETOR_SELF_REVIEW
assurance_level: OWNER_SELF_REVIEW
independent_assurance_claimed: false
external_staff_required_for_governance: false
~~~

- `R-USER` 수행 결과를 독립 사용자 대표의 승인이라고 부르지 않는다. 실제 사용자 현실의 근거는 사전 등록된 기준에 따라 수집한 참가자 응답·행동 자료에서만 얻는다.
- `R-PRIVACY` 수행 결과를 독립 개인정보 감사 또는 법률 의견이라고 부르지 않는다.
- `R-VERIFY` 수행 결과를 독립 검증이라고 부르지 않는다. 동일 소유자가 동결된 입력·규칙·스크립트로 다시 실행한 `OWNER_SELF_REVIEW` 또는 `REPRODUCIBILITY_CHECK`라고 기록한다.
- 외부 발표, 제안서, 랜딩페이지와 게이트 결정에는 독립 검증을 받았다는 표현을 사용하지 않는다.
- 모호하거나 자체 검산에서 불일치한 증거는 더 유리한 값으로 고치지 않고 `disputed` 또는 `INCONCLUSIVE`로 제외한다.

`GO`는 사전 등록된 내부 기준을 개인사업자 본인이 충족했다고 판단했다는 뜻이다. 시장 적합성, 법적 적합성, 의료·안전성 또는 독립 검증 완료를 뜻하지 않는다.

## 통제 방식

인적 분리 대신 다음 절차 통제를 사용한다.

1. 결과를 보기 전에 질문, 제외 규칙, 지표, 임계값과 오퍼 버전을 해시로 동결한다.
2. 원자료 처리와 집계를 분리된 단계로 수행하고 각 실행 시각·입력 해시·출력 해시를 남긴다.
3. 자체 검산에서는 첫 판정값을 숨긴 상태로 가능한 항목을 다시 분류하고, 불일치는 동결된 결정 트리로만 처리한다.
4. 개인정보 체크리스트를 데이터 수집 전과 삭제 후 각각 실행한다.
5. 자기 이해충돌과 보증 한계를 모든 게이트 결정문에 기록한다.
6. 법률·규제·세무·상표 또는 안전 판단에 자격·전문 의견이 실제로 필요한 경우 이 거버넌스 결정으로 그 요건을 면제하지 않는다.

## B-00·B-01에 미치는 영향

- 기존 B-00 서명 기록 `AUTH-V0-B00-20260814-001`은 Git에서 원문을 확인할 수 없고, 이전 문서에는 책임 모델이 `INDIVIDUAL_PROJECT`로 투영돼 있었다. 원문을 개인사업자 책임 모델과 대조하거나 정정하기 전에는 `SUBMITTED`보다 높이지 않는다.
- B-01은 네 명을 배정하는 방식이 아니라 개인사업자 본인 한 명이 일곱 기능의 책임을 수락하는 통합 역할 기록으로 바꾼다.
- 사용자의 이번 지시는 거버넌스 모델 선택을 확정하지만, Git 외부의 B-01 서명 기록 ID를 생성하거나 B-00 원문 대조를 완료한 것으로 보지 않는다.

## 적용 범위 밖

이 결정은 V0·V1·V2 사전 검증의 인력 구조만 바꾼다. 제품 구현 이후의 보안 시험, 스토어 제출, 의료·건강 표현 분류, 개인정보 법적 의무, 회계·세무, 상표 사용 가능성 또는 법령이 요구하는 자격·외부 심사를 자동 면제하지 않는다. G3 이후 거버넌스는 해당 단계 진입 전에 다시 결정한다.

## 대체되는 규칙

V0·V1·V2 범위에서는 기존 문서의 다음 요구가 이 결정으로 대체된다.

- 최소 네 명 또는 네 석의 인적 분리
- 제품 작성자와 `R-USER`의 인적 분리
- 별도 `R-VERIFY` 확보
- 같은 증거의 수집자와 검산자의 인적 분리
- 독립 검증 완료를 `GO`의 필수 조건으로 두는 규칙

데이터 최소화, 동의, 접근 통제, 삭제, 사전 등록, 증거 계보, 실패 시 중단과 사실에 근거한 보고 의무는 그대로 유지한다.
