# Measure: FitPulse V0 authorization, evidence handling, and brand preflight

## 결론

현재 V0는 실행할 수 없다. B-00 대체 기록과 B-01 통합 역할 기록의 참조 ID는 제출됐지만 서명 시각과 원문 대조 완료 여부를 확인할 수 없고, 저장소·모집·오퍼·상표 전문가 경로도 배정됐다는 근거가 없다.

이 문서는 실행값을 추측해 채우는 대신 다음을 고정한다.

1. 누가 어떤 원문을 제한 저장소에 준비해야 하는지
2. 어떤 정보만 Git에 남길 수 있는지
3. V0 내부 조사와 합성 자료 삭제 리허설을 어떤 순서로 시험할지
4. 브랜드 후보를 어떤 검색 단위와 위험 규칙으로 판정할지
5. 어떤 조건에서만 `GO/LOOP/STOP` 결정문을 발행할지

실제 입력 방법은 [B-00~B-05 승인·증거 인수 가이드](./fitpulse-v0-authorization-evidence-intake-guide-20260814.md)를 따른다.

## 3. V0 목적과 비목적

### 목적

- 연구·예산·외부 계약을 승인할 실제 권한을 확인한다.
- 개인사업자 본인에게 일곱 책임 기능과 자체 검산 경로를 배정한다.

- V1 모집·동의·오퍼 문서를 동결할 수 있는 상태인지 판정한다.

### 비목적

- 참가자 모집·인터뷰·건강정보·운동기록 수집
- 실제 결제·예약금·사례비 지급

- 최종 상표 사용 가능성에 대한 비전문가 결론
- 도메인·핸들 구매, UI·로고·스토어 메타데이터 제작
- V1 문제 신호나 지불 증거의 생성

## 7. 역할 계약

실제 담당자는 개인사업자 본인 한 명인 `R-OWNER`다. 아래 역할 코드는 인력을 나누는 좌석이 아니라 같은 소유자가 순서대로 수행하고 별도 로그를 남길 책임 기능이다.

| 기능 모자 | V0 책임 | 현재 배정 | 자체 검토 통제 |
|---|---|---|---|
| `R-SPONSOR` | 비용·시간 상한과 최종 `GO/STOP` | `R-OWNER` — 서명 기록 대기 | 결정 전 증거·미충족 조건 목록 확인 |
| `R-PRODUCT` | 후보·범위·V1 준비 문서 관리 | `R-OWNER` — 서명 기록 대기 | 결과 확인 후 범위·임계값 변경 금지 |
| `R-EVIDENCE` | 검색 질의·근거 ID·계보 관리 | `R-OWNER` — 서명 기록 대기 | 입력·출력·실행 시각과 해시 기록 |
| `R-USER` | 사용자 언어·브랜드 오인 가능성 자체 점검 | `R-OWNER` — 서명 기록 대기 | 독립 사용자 대표 주장 금지; 참가자 원자료로만 사용자 현실 판단 |
| `R-PRIVACY` | 저장·접근·삭제·사고 통제 | `R-OWNER` — 서명 기록 대기 | 수집 전·삭제 후 체크리스트와 불확실성 시 중단 |
| `R-VERIFY` | 문서 해시·질의 완결·리허설 결과 자체 검산 | `R-OWNER` — 서명 기록 대기 | 첫 결과와 분리한 재실행; 독립 검증 주장 금지 |
| `R-FINANCE` | 모집·사례비·오퍼·환불 증거 검토 | `R-OWNER` — 서명 기록 대기 | 결과 확인 뒤 가격·통과 기준 변경 금지 |

V0~V2에는 `R-OWNER` 한 명과 일곱 기능의 통합 수락 기록이 필요하다. 외부 역할 인력은 필수 조건이 아니며, 모든 결과는 `OWNER_SELF_REVIEW`로 표시한다.

## 9. 브랜드 후보·검색 단위

### 9.1 후보 정규화

후보마다 다음 순서로 `normalized_candidate`를 만든다.

1. Unicode NFKC를 적용한다.
2. 영문을 소문자로 바꾼다.
3. 공백, 하이픈과 구두점을 제거한다.

`normalized_candidate`가 같으면 후보 한 개로 센다. 원문, 정규화 결과와 변환 도구·버전은 EVD에 기록한다.

### 9.2 필수 질의

후보마다 다음 질의를 모두 실행한다.

- 정확명
- 공백 변형
- 하이픈 변형
- 한글 표기
- 영문 표기
- 통용 로마자 표기
- 발음 유사어

검색 대상은 다음과 같다.

1. 한국 Google Play
2. 한국 App Store
3. 일반 웹 검색
4. KIPRIS 상표 상세검색
5. B-05가 정한 도메인 패턴
6. B-05가 정한 공식 계정 플랫폼
7. 적용 시 WIPO Global Brand Database와 USPTO

각 질의에는 문자열, 필터·관할, 결과 URL, 확인 시각, 검토자 역할 ID와 비민감 스크린샷 ID를 기록한다. 검색 결과가 없었다는 주장에도 동일한 기록이 필요하다.

### 9.3 후보 EVD 스키마

~~~yaml
evidence_id: EVD-YYYY-NNN-brand-candidate-slug
status: DRAFT
candidate_id: REQUIRED
candidate_text: REQUIRED
normalized_candidate: REQUIRED
normalization_tool_and_version: REQUIRED
jurisdiction: KR
queries:
  exact: []
  spacing_variants: []
  hyphen_variants: []
  korean_forms: []
  english_forms: []
  romanized_forms: []
  phonetic_variants: []
surfaces:
  google_play_kr: NOT_RUN
  app_store_kr: NOT_RUN
  general_web: NOT_RUN
  kipris_class_09: NOT_RUN
  kipris_class_42: NOT_RUN
  domain_patterns: NOT_RUN
  required_handle_platforms: NOT_RUN
  wipo_optional: NOT_RUN
  uspto_optional: NOT_RUN
~~~

`YYYY`, `NNN`, `slug`와 모든 `REQUIRED` 값은 산출 시 실제 값으로 바꾼다. 자리표시자가 남은 EVD는 승인 근거로 사용하지 않는다.

### 9.4 위험 등급

| 등급 | 조건 | V0 계수 |

## 13. V0 판정 알고리즘

판정은 결과 확인 뒤 바꾸지 않는다.

~~~text
IF B-00..B-05 중 하나라도 OWNER_VERIFIED 또는 적용 시 VERIFIED가 아님
  THEN STOP
ELSE IF 통합 R-OWNER 서명 또는 일곱 기능 매핑 검사가 실패
  THEN STOP
ELSE IF 합성 자료 삭제 리허설이 PASS가 아님
  THEN STOP
ELSE IF 전문가가 예비 검토한 계수 가능 후보가 1개 이상이고
        V1 문서·오퍼를 동결할 수 있음
  THEN GO
ELSE IF 역할·개인정보·오퍼·전문가 경로 차단은 없고
        후보 검색 또는 문서 품질만 미완이며
        LOOP를 사용하지 않았음
  THEN LOOP 1회, 최대 5영업일
ELSE
  STOP
~~~

`GO`는 V1 파일럿 3명만 허용한다. 공개 모집, 본 조사, 랜딩 수요 실험과 제품 구현은 허용하지 않는다.
