## 이번 단계의 결과물

하나의 메시지와 하나의 CTA를 가진 모바일 우선 랜딩을 공개하고, 실제 방문자가 대기자 등록까지 진행하는지를 측정한다. 첫 공개 버전에서는 A/B 테스트보다 기준선 확보를 우선한다.

## 대상과 메시지

- 대상: 근력운동 경력 6개월~3년, 주 2회 이상 운동하며 Android 또는 Galaxy 기기를 쓰는 사람
- 반복 문제: 다음 운동의 중량·반복 수를 정할 근거가 부족함
- 메인 문구: **오늘 몇 kg을 들어야 할지 알려주는 근력운동 코치**
- 보조 문구: 지난 운동 기록을 바탕으로 다음 중량과 반복 수를 제안하는 앱을 준비하고 있습니다.
- CTA: **출시 알림 신청하기**

이 단계에서는 실제 추천 기능이 있는 것처럼 표현하지 않는다. 부상 회피, 회복 데이터 조절, 의료적 안전성도 랜딩의 효능 주장으로 사용하지 않는다.

## 페이지 구성

1. Hero: 문제 문구, 개발 준비 중 안내, 1차 CTA
2. 문제: 다음 중량을 감으로 정하거나 이전 기록을 찾느라 생기는 불편
3. 제안 흐름: 빠르게 기록 → 지난 수행 확인 → 다음 목표 제안
4. 화면 시안: 실제 구현이 아닌 개발 예정 화면임을 표시
5. 신뢰: 데이터 최소 수집, 삭제 요청, 효능 과장 금지
6. 대기자 폼: 이메일, 필수 동의, 제출
7. 선택 설문과 FAQ

### 행동 이벤트

| 이벤트 | 의미 | 허용 속성 |
|---|---|---|
| `landing_view` | 유효 페이지 노출 | `page_version`, `channel_code` |
| `primary_cta_click` | 주 CTA 클릭 | `page_version`, `position` |
| `waitlist_submit` | 유효 대기자 등록 | `page_version`, `channel_code` |
| `survey_complete` | 선택 설문 완료 | `page_version` |

이메일과 자유 입력값은 이벤트 속성에 넣지 않는다.

## 기술 범위

- 소스 위치: `landing/`
- 모바일 우선 반응형 웹
- 입력 검증과 접근 가능한 오류·성공 상태
- 대기자 저장과 이벤트 기록을 서로 다른 서버 경로로 처리
- 저장 공급자에 종속된 코드는 작은 어댑터 경계 안에 둔다.
- 실제 공개 전에 선택된 저장·분석 공급자와 개인정보 안내를 일치시킨다.

### 2026-08-14 검증 기록

- 외부 접근을 중지하고 현재 소유자 한 명만 허용했다. 허용 그룹과 외부 방문자는 0명이다.
- `waitlist_submit`, `survey_complete`, `interview_opt_in`은 서버가 실제 저장 결과를 기준으로 한 번만 기록한다. 클라이언트는 `landing_view`, `primary_cta_click`만 보낼 수 있다.
- 이메일 존재 여부와 내부 ID는 응답에 노출하지 않는다. 설문과 삭제는 HttpOnly 관리 세션으로만 연결한다.
- 확인 전 이메일 14일, 그 밖의 대기자·설문·이벤트 365일, 요청 제한 기록 1시간의 일일 삭제 작업과 직접 삭제 경로를 구현했다.
- 프로덕션 Worker 통합 시험 8개가 보안 헤더, 교차 사이트 거부, 중복 등록, 설문·삭제 권한, 이벤트 중복 방지, 요청 제한, 외래키와 보존 정리를 통과했다.
- 실제 브라우저 QA에서 필수 개인정보 동의 상태가 선택 인터뷰 동의로 재사용되는 결함을 발견해 별도 제어 상태로 분리했고, 선택하지 않은 초기값과 전체 등록·설문·삭제 흐름을 다시 확인했다.

현재 공개 판정은 **NO-GO**다. 이메일 확인·발송 공급자, D1 및 호스팅 로그의 실제 처리 국가·수탁 범위·백업 보존, 공개 트래픽용 Turnstile 또는 동등한 남용 방어와 비용 중단 조건이 확정될 때까지 소유자 전용 상태를 유지한다.

## 측정과 판단

주 지표는 `waitlist_submit / landing_view`다. 보조 지표는 CTA 클릭률, 선택 설문 완료율, 인터뷰 안내 수신 선택률과 채널별 획득비용이다.

첫 데이터가 쌓이기 전에는 고정 Go/No-Go 수치를 성공 기준처럼 사용하지 않는다. 초기 100개 유효 방문에서 계측 오류와 주요 이탈 지점을 먼저 확인하고, 실제 기준선을 기록한 뒤 다음 실험의 임계값과 A/B 여부를 결정한다.
