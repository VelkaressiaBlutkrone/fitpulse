## 결론

이 페이지는 제품을 판매하거나 포지셔닝 반응을 시험하는 랜딩페이지가 아니다. 조건에 맞는 연구 참가자가 자신의 최근 운동 의사결정 과정을 관찰하는 V1 연구에 지원하도록 안내하는 **중립 모집 페이지**다.

페이지는 다음 중 어느 것도 먼저 말하지 않는다.

- AI 추천
- 자동 중량·반복 제안
- 회복 데이터 기반 조절
- 부상 회피 또는 재활
- 오프라인 기록 복구
- 가격, 무료 체험, 출시 시점

이 제한은 해결책을 본 참가자가 인터뷰에서 계획된 문제를 되풀이하는 일을 막는다. 모집 전환율은 채널 운영 지표일 뿐 문제 수요나 지불 의사의 증거로 세지 않는다.

## 1. 권위와 실행 순서

상위 계획과 이 문서가 충돌하면 상위 계획이 우선한다.

| 우선순위 | 문서·결정 | 적용 |
|---:|---|---|
| 1 | 루트 `CLAUDE.md` | 추측 금지, 문서 검증, 신규 작업 브랜치 |
| 2 | V0·V1 브랜드 및 문제 검증 실행 계획 | 모집 기준, 원자료 경계, 역할, `30/10/10/5/5`, 사건·중단 규칙 |
| 3 | `GATE-V0`·`V1-MAIN-READY` 결정 | 페이지를 어떤 모드로 열 수 있는지 통제 |
| 4 | 이 문서 | 모집 페이지 카피, 데이터 흐름, 이벤트, 수용 시험 |
| 5 | Wiki 문서 | 역사 자료. 현재 모집 범위나 제품 약속을 정하지 않음 |

실행 순서는 다음과 같다.

~~~text
문서·로컬 시안 작성
        │
        ├─ V0 GO 전 ─▶ 외부 URL 게시·참가자 연락 금지
        │
        ▼
V0 GO ─▶ 초대형 파일럿 3명 모집에만 사용
        │
        ▼
V1-MAIN-READY ─▶ B-03에 등록된 채널에서 본 조사 모집
        │
        ▼
모집 종료/STOP ─▶ CTA 닫기 + 신청 처리 + 데이터 수명주기 실행
~~~

`V0 GO`는 파일럿 3명만 허용한다. 공개 커뮤니티 게시, 유료 광고와 본 조사 모집은 `V1-MAIN-READY` 전에는 금지한다.

## 2. 목적과 비목적

### 목적

1. 모집 기준을 지원자가 읽고 스크리너로 이동할 수 있게 한다.
2. 연구 활동, 시간, 사례비 조건과 자료 범위를 과장 없이 설명한다.
3. 제품 해결책을 노출하지 않고 적격 참가자를 모집한다.
4. 채널별 모집 운영 상태를 비민감 집계로 확인한다.
5. 모집을 즉시 닫고 신청자에게 종료 상태를 알릴 수 있게 한다.

### 비목적

- 대기자 수 확보
- Hero A/B 테스트
- 가격 또는 지불 의사 측정
- 제품·앱·브랜드 홍보
- 건강 상태·통증·부상 진단 또는 상담
- 설문 응답을 문제 신호로 계수
- V1 인터뷰를 대체하는 대규모 설문

## 3. 모집 대상과 페이지 경계

페이지에 표시하는 자격 기준은 상위 V1 계획과 동일하다.

1. 만 19세 이상 한국 거주자
2. Android 스마트폰 또는 Galaxy Watch 사용자
3. 근력운동 경력 6개월 이상 3년 이하
4. 최근 8주 동안 주 3~5회 근력운동
5. 앱·메모·스프레드시트에 3개월 이상 운동 기록 보유
6. 다음 운동의 중량·반복·세트 수를 본인이 결정
7. 최근 세 번의 운동 기록을 인터뷰에서 관찰 가능
8. 질환 치료·통증 재활·의료 조언이 아닌 운동 기록 연구 목적으로 참여

페이지는 자격을 확정하지 않는다. `V1-03`에서 승인된 스크리너가 적격·제외를 판정한다. 페이지 분석 이벤트에 적격 여부, 운동 기록, 건강정보나 연락처를 보내지 않는다.

## 4. 페이지 정보 구조와 실제 원고

페이지는 모바일 우선 단일 페이지로 구성한다. 브랜드 후보가 V0에서 승인되기 전에는 `FitPulse`를 공개 페이지 제목이나 도메인에 사용하지 않는다. 임시 공개 명칭은 **근력운동 기록 연구**로 고정한다.

### 4.1 Hero

~~~text
[상단 표기]
만 19세 이상 Android 근력운동 기록 사용자 연구

[H1]
다음 운동의 중량과 횟수를 어떻게 정하시나요?

[본문]
최근 세 번의 실제 운동 기록을 함께 보면서
운동 전 목표를 정하고 기록하는 과정을 알아보는 연구입니다.
제품 사용 경험이나 긍정적인 의견을 요구하지 않습니다.

[CTA]
참여 조건 확인하기

[보조 문구]
조건 확인 후 별도 동의를 거쳐 신청합니다.
신청만으로 참여가 확정되거나 결제가 발생하지 않습니다.
~~~

### 4.2 참여 조건

~~~text
[제목]
이런 분을 찾습니다

• 만 19세 이상이며 한국에 거주합니다.
• Android 스마트폰 또는 Galaxy Watch를 사용합니다.
• 근력운동을 6개월 이상 3년 이하 해왔습니다.
• 최근 8주 동안 주 3~5회 운동했습니다.
• 최근 3개월 이상의 운동 기록이 있습니다.
• 다음 운동의 중량·횟수·세트 수를 직접 정합니다.

[안내]
치료·재활·통증 상담을 제공하는 연구가 아닙니다.
해당 목적의 참여는 받지 않습니다.
~~~

“주 3~5회”의 실제 적격 판정은 최근 8주 세션 수 24~40회로 계산한다. 페이지에는 단순 문구만 표시하고 계산은 승인된 스크리너가 수행한다.

### 4.3 참여 내용

~~~text
[제목]
참여하면 무엇을 하나요?

1. 짧은 참여 조건 확인
2. 선정된 경우 일정 조율과 연구 동의
3. 약 60분 동안 최근 운동 기록 세 번을 보며 진행하는 인터뷰
4. 현재 도구에서 기록을 내보낼 수 있는지 선택적으로 확인

[사례비]
인터뷰를 끝까지 완료하면 의견의 긍정·부정과 관계없이
사전에 안내한 사례비를 지급합니다.
~~~

사례비 금액, 지급 수단과 지급 시점은 B-03에서 실제 값이 승인된 뒤 페이지와 스크리너에 같은 값으로 반영한다. 자리표시자를 공개하지 않는다.

### 4.4 자료와 안전

~~~text
[제목]
자료는 이렇게 다룹니다

• 신청 연락처와 연구 응답은 분리해서 보관합니다.
• 동의한 항목만 관찰하며 이메일·메신저로 운동 파일을 받지 않습니다.
• 원자료는 공개 GitHub 저장소에 올리지 않습니다.
• 참여 전이나 참여 후에도 정해진 연락 경로로 철회할 수 있습니다.
• 이 연구는 의학적 진단, 치료 또는 운동 처방을 제공하지 않습니다.

[링크]
연구 개인정보 안내 보기
~~~

실제 개인정보 안내 URL, 처리자, 연락처, 항목, 목적, 보유기간과 국외 이전 여부는 B-02 및 V1-02 승인본에서 가져온다. 승인 전에는 링크가 있는 것처럼 공개하지 않는다.

### 4.5 FAQ

~~~text
Q. 이미 만들어진 앱을 시험하나요?
A. 아닙니다. 현재 사용 중인 기록 방식과 의사결정 과정을 알아보는 사전 연구입니다.

Q. 운동이나 건강 상담을 받을 수 있나요?
A. 아닙니다. 진단·치료·재활·개별 운동 처방을 제공하지 않습니다.

Q. 참가하려면 결제해야 하나요?
A. 아닙니다. 신청과 인터뷰 참여에 결제는 필요하지 않습니다.

Q. 어떤 자료를 보나요?
A. 동의한 경우 최근 세 번의 운동 기록과 목표를 정한 과정을 함께 봅니다.
   원본 파일은 승인된 절차 밖에서 전송받지 않습니다.

Q. 신청하면 모두 참여할 수 있나요?
A. 연구 기준과 모집 구성을 확인한 뒤 개별적으로 안내합니다.
~~~

### 4.6 종료 상태

모집 종료 또는 `STOP` 시 신청 CTA를 제거하고 다음 문구만 표시한다.

~~~text
현재 모집이 종료되었습니다.

이미 신청하신 분께는 승인된 연락 경로로 처리 상태를 안내합니다.
새 신청이나 대기자 등록은 받지 않습니다.
~~~

## 5. 금지 카피 검사

페이지 본문, 메타 태그, 이미지 대체 텍스트, 공유 미리보기와 자동응답에서 다음 표현을 금지한다.

| 범주 | 금지 예 | 이유 |
|---|---|---|
| 해결책 유도 | AI 추천, 자동 진행, 오늘 몇 kg, 회복 기반 코칭 | V1 문제 관찰 오염 |
| 의료·부상 | 부상 이력 분석, 피해야 할 동작, 안전한 루틴, 재활 | 초기 사용자 제외·분류 미확정 |
| 제품 약속 | 개발 중 앱, 4개월 뒤 출시, 기본 기능 무료 | 구현·일정·상품 미승인 |
| 가격·혜택 | 월 9,900원, 6개월 무료, 얼리버드 | B-04 미확정·지불 측정 오염 |
| 기기 과장 | Apple Watch 연동, 모든 웨어러블 지원 | Android 연구 범위와 불일치 |
| 과장된 익명성 | 완전 익명, 어떤 정보도 수집하지 않음 | 연락·동의·서비스 로그 경계와 불일치 가능 |

연구 제목과 FAQ에 `FitPulse`를 넣으려면 V0에서 해당 출시 후보의 사용 범위가 승인돼야 한다.

## 6. 신청·동의·원자료 흐름

~~~text
공개 모집 페이지
  │  허용: 페이지 버전·채널 코드의 비민감 집계
  │  금지: 이메일·전화·운동·건강 값
  ▼
B-02 승인 스크리너
  │  자격 응답과 제외 사유
  ├── 부적격 ─▶ 연락처를 추가 수집하지 않고 승인된 기간 후 삭제
  │
  └── 적격 후보
        │
        ├─ 연락처 저장소 ──▶ 일정 조율
        │      신원 매핑 키는 연구 원자료와 분리
        │
        └─ 연구 동의 ──▶ 승인 연구 저장소
                           인터뷰·관찰·약정 원자료
~~~

공개 페이지와 스크리너 사이에는 이메일, 전화번호, 참가자 ID, 건강 응답을 URL 쿼리·UTM·리퍼러에 넣지 않는다. 채널 코드는 B-03의 불투명 허용목록 값만 사용한다.

스크리너가 해외 서비스를 사용하거나 다른 해외 처리자에게 위탁·보관한다면 실제 데이터 흐름을 기준으로 처리 근거와 고지를 검토한다. 국외 이전 동의를 근거로 선택할 경우 개인정보 보호법 제28조의8이 요구하는 항목·국가·시기·방법·수령자와 연락처·목적·기간·거부 방법과 효과를 실제 값으로 제시한다.

운동·회복·통증 등 건강정보를 처리하면 일반 개인정보와 분리된 민감정보 처리 동의와 안전조치를 R-PRIVACY 및 법무 검토자가 승인한다. 이 문서는 법률 자문을 대신하지 않는다.

## 7. 도구와 공급자 선택

Framer, Carrd, Tally, Google Forms, Google Sheets, GA4, Clarity 또는 특정 메일 도구를 승인된 선택으로 간주하지 않는다. R-PRODUCT와 R-PRIVACY는 V1-02에서 실제 공급자를 정하고 다음 표를 채운다.

| 필드 | 필수 값 |
|---|---|
| page_host | 실제 법인·서비스명, 계정 소유자, URL |
| screener_provider | 실제 법인·서비스명, 저장 위치, 관리자 |
| contact_store | 연구 응답과 분리된 연락처 저장소 |
| research_store | B-02 승인 원자료 저장소 |
| analytics_provider | 비민감 이벤트만 처리하거나 `none` |
| email_provider | 실제 법인·서비스명 또는 `none` |
| processor_countries | 공급자별 실제 처리 국가 |
| subprocessors | 적용되는 재위탁자 목록과 확인일 |
| retention | 자료별 보존기간과 삭제·백업 전파 방식 |
| access_matrix | 역할별 읽기·내보내기·삭제 권한 |
| breach_contact | 사건 책임자와 연락 경로 |
| approval_ids | 개인정보·법무·보안 승인 기록 ID |

공급자 문서로 처리 국가나 재위탁자를 확인할 수 없으면 해당 도구를 사용하지 않는다. 무료 티어라는 이유로 개인정보 적합성을 추론하지 않는다.

## 8. URL·도메인·검색 노출

- V0 브랜드 승인 전에는 조직이 통제하는 중립 연구 도메인 또는 승인된 연구 플랫폼 URL만 사용한다.
- `preview.fitpulse.*` 같은 주소는 B-05와 V0 후보 승인 전 사용하지 않는다.
- 검색 유입이 연구 목적이 아니므로 `noindex` 적용 가능 여부를 호스트에서 확인하고 적용 결과를 검증한다.
- 페이지 URL에는 참가자·연락처·응답 값을 넣지 않는다.
- QR 코드는 B-03에 등록된 채널별 URL만 인코딩하고 게시 장소의 사전 허락을 증거 ID로 남긴다.
- 모집 종료 시 모든 채널 URL을 종료 상태로 바꾸고 새 신청을 받지 않는다.

## 9. 최소 분석 이벤트

분석 공급자를 승인한 경우에만 다음 이벤트를 사용한다.

| 이벤트 | 발생 | 허용 파라미터 | 금지 파라미터 |
|---|---|---|---|
| `research_recruitment_view` | 페이지가 표시됨 | `page_version`, `channel_code`, `device_class` | 전체 URL, 연락처, 사용자 ID |
| `eligibility_cta_click` | 스크리너 이동 CTA | `page_version`, `channel_code`, `position` | 스크리너 답변, 적격 여부 |
| `recruitment_page_closed_view` | 종료 페이지 표시 | `page_version`, `channel_code` | 신청 상태, 참가자 ID |

다음 값은 공개 페이지 분석에 보내지 않는다.

- `screening_eligible` 또는 제외 사유
- 인터뷰 동의·일정·완료 상태
- 운동 빈도·경력·사용 앱
- 수면·심박·체중·통증·부상
- 이메일·전화번호·쿠키와 결합된 참가자 ID

세션 녹화와 히트맵은 기본적으로 사용하지 않는다. 필요성이 별도 승인되더라도 스크리너·동의·완료 페이지에는 로드하지 않으며, 공개 모집 페이지만 엄격한 마스킹과 실제 녹화 검사를 통과한 뒤 사용할 수 있다.

## 10. UTM과 채널 통제

URL 형식은 다음 허용 필드만 사용한다.

~~~text
?utm_source={B03_channel_code}&utm_medium={approved_medium}&utm_campaign=v1_recruitment
~~~

`utm_content`로 해결책·부상·회복 세그먼트를 나누지 않는다. V1 모집은 같은 중립 카피를 사용한다.

| 통제 | 규칙 |
|---|---|
| 채널 등록 | `MEASURE-V1` 시작 전에 코드·담당자·예산·허가 증거 고정 |
| 채널 상한 | 유효 참가자 15명에서 해당 채널 닫기 |
| URL 검증 | 허용목록 외 코드면 일반 종료 페이지로 이동하거나 계수 제외 |
| 지인 편향 | 사전 관계를 원자료에 기록하고 집계에서 별도 표시 |
| 커뮤니티 | 게시 규정과 운영자 허락을 확인한 채널만 사용 |
| 오프라인 QR | 게시 장소 책임자의 허락 증거가 있는 코드만 사용 |

## 11. 운영 모드

| 모드 | 진입 조건 | 허용 | 금지 |
|---|---|---|---|
| `LOCAL_DRAFT` | 문서 작성 | 로컬 시안·카피 검사 | 공개 URL, 실제 신청 |

| `MAIN_RECRUITMENT` | `V1-MAIN-READY`, B-03 채널 활성 | 승인 채널 모집 | 새 카피·스크리너·오퍼 변경 |

운영 모드는 서버나 도구의 한 필드로 자동 추론하지 않는다. R-EVIDENCE가 변경 시각, 사유와 승인 ID를 모집 대장에 기록한다.

## 17. 승인 기준

이 문서는 다음을 모두 충족할 때만 `IN_REVIEW`로 이동한다.

1. B-00~B-03과 V1-01~04의 실제 승인 ID가 연결된다.
2. 페이지 원고에 해결책·가격·출시 약속·의료 주장이 없다.
3. 실제 공급자, 처리 국가, 접근자, 보존·삭제와 사고 연락 경로가 확인된다.
4. 스크리너, 연락처와 연구 원자료가 분리된다.
5. RP-001~014의 실행 방법과 기대 결과가 실제 구현 도구에 맞게 채워진다.
6. V0 GO 전 공개 금지와 `V1-MAIN-READY` 전 본 조사 금지가 기술·운영으로 모두 차단된다.
7. R-USER, R-PRIVACY와 R-VERIFY가 각자 검토한다.

현재 B-00~B-03과 공급자·승인 기록이 없으므로 실행 상태는 `BLOCKED`다. 문서 작성은 모집 승인이 아니다.
